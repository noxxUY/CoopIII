Features

The real game, played together

Everything in the repo was written from scratch. What you bring is your own copy of GTA III.

Up to 8 players

A dedicated server relays everyone’s movement, cars and chat. Anyone can run one; friends join with an address and a name.

Keeps your mod stack

Ships as a single .asi loaded by Ultimate ASI Loader, built to live alongside SilentPatch, Mod Loader and CLEO.

Single player stays untouched

Co-op only switches on when the game starts from the CoopIII launcher. Start it any other way and it’s plain GTA III.

How it works

Three steps to co-op

The Setup and the launcher do the checking for you, so a wrong game version never gets as far as a crash.

  1. 01

    Run the Setup

    Installs CoopIII and the Essential Pack into your GTA III v1.0 folder.

  2. 02

    Start from the launcher

    It checks the game, then starts GTA III with co-op switched on.

  3. 03

    Join a friend

    Type the server address and your name. The default port is 2001.
